\section{Task 2: Trajectory Generation (Newton's Method)}

We employed a Newton-type method for optimal control (Differential Dynamic Programming approach) to generate trajectories transitioning between equilibria.

\subsection{Reference Generation}
The non-convex nature of the problem requires a reasonable reference trajectory, even though not feasible. We explored two reference generation methods:
\begin{enumerate}
\item \textbf{Stepwise:} A naive instantaneous switch from start to goal. This often results in poor convergence due to the large discontinuity.
\item \textbf{Polynomial Interpolation (Poly 5):} We generated smooth references for positions and velocities using 5th-order polynomials. This provided a kinematic guide that respects boundary conditions, significantly aiding the solver.
\end{enumerate}

Applying the standard Newton method directly to complex maneuvers revealed several issues:
\begin{itemize}
\item \textbf{Local Minima:} Being the manouver complex and the time horizon large, there would be many local minimum in the Loss landscape. 
When using an initial guess that is far off from the real trajectory, it pushes the loss far away from the local minimum that guarantees a solution. 
Once we land inside a minimum, it is not possible to move out of it.

\subsection{Dynamic Horizon Extension Strategy}
To overcome the "local minimum trap" athe difficulty of solving long-horizon problems from scratch, we implemented a \textbf{Dynamic Horizon Extension} strategy in "trajectory generation newton.py".

\textbf{The Algorithm:}
\begin{enumerate}
\item \textbf{Start Small:} Solve the optimal control problem for a short time horizon (e.g., $T_{curr} < T_{final}$) where the goal is reachable or the DARE terminal cost effectively guides the system.
\item \textbf{Converge:} Run the Newton solver until convergence for this sub-problem.
\item \textbf{Extend:} Use the solution $x^*(t)$ from the current phase as the initial guess for an extended horizon $T_{curr} + \Delta T$. The new tail of the guess is padded with the target equilibrium.
\item \textbf{Repeat:} Iterate this process until the full task duration is covered and the terminal error is below a tolerance ($\|x_T - x_{target}\| < \epsilon$).
\end{enumerate}

\textbf{Results:} This approach proved robust. By incrementally solving the problem, the solver is always "warm-started" with a feasible trajectory. Tasks that failed with a direct solve (like the "Topside Pump") converged reliably using this extension scheme.
