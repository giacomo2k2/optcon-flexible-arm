\section{Task 2: Trajectory Generation (Newton's Method)}

We employed a Newton-type method for optimal control, specifically a Differential Dynamic Programming (DDP) approach, to generate feasible trajectories transitioning between system equilibria.  This method iteratively optimizes the control sequence by utilizing quadratic approximations of the cost function and linear approximations of the system dynamics.

\subsection{Reference Generation}
Given the non-convex nature of the optimization landscape, the solver requires a reasonable reference trajectory to guide convergence, even if that reference is dynamically infeasible. We analyzed two distinct generation methods:

\begin{enumerate}
    \item \textbf{Stepwise:} A naive approach involving an instantaneous switch from the initial state $x_{start}$ to the goal state $x_{goal}$. This introduces a large discontinuity in the error term, often leading to poor convergence or aggressive control spikes.
    \item \textbf{Polynomial Interpolation (Poly 5):} We generated smooth references for joint positions and velocities using 5th-order polynomials.  This method ensures kinematic consistency by respecting boundary conditions (position, velocity), thereby significantly aiding the solver in finding a feasible solution.
\end{enumerate}

\subsection{Performance Analysis: Stepwise vs. Polynomial}

The choice of reference trajectory significantly impacts the solver's performance. When applying Newton's method to the \textbf{Stepwise} reference, we observed significant limitations. As seen in Figure \ref{fig:newton_stepwise}, the instantaneous jump in the reference creates a large error gradient at the transition point. The solver attempts to compensate with an infeasible spike in control torque $u$, often pushing the system into unstable regions.

\begin{figure}[H]
    \centering
    \includegraphics[width=0.6\linewidth]{figs/placeholder.jpg}
    \caption{Newton's method applied to Swing Up using Stepwise reference. Note the control discontinuity.}
    \label{fig:newton_stepwise}
\end{figure}

Conversely, the \textbf{Polynomial (Poly 5)} reference provides a physically plausible kinematic guide. However, physical constraints inherent to the under-actuated flexible link still present challenges:

\begin{itemize}
    \item \textbf{Energy Transfer (Elbow Up):} During swing-up motions, kinetic energy must be efficiently transferred to potential energy. The polynomial reference guides this transfer smoothly.
    \item \textbf{Energy Dissipation (Elbow Down):} In downward motions, the passive second link cannot be directly braked. Since the system friction is low, the controller cannot rely on passive dissipation; it must actively pump energy out of the system via coupling, which is difficult if the reference demands a stop faster than the system's natural dynamics allow.
\end{itemize}

\subsection{Optimization Challenges}
Applying the standard Newton method directly to complex, long-horizon maneuvers revealed several critical numerical and theoretical issues:

\begin{itemize}
    \item \textbf{Non-Convex Optimization Landscape:} For complex maneuvers, the trajectory manifold is highly non-linear. The optimization landscape is riddled with local minima.  If the initial guess falls within the basin of attraction of a local minimum, representing a partial swing or a stalled state, the solver is unable to escape to the global optimum.

    \item \textbf{Long Time Horizons and Sensitivity:} Extending the time horizon $T$ exponentially increases the complexity of the solution space. A short horizon simplifies the optimization but fails to stabilize the system exactly at the equilibrium. Conversely, a long horizon increases the condition number of the Hessian matrix. Small changes in initial inputs propagate through the sensitivity matrix $\prod_{k=0}^{T-1} A_k$, causing massive deviations in terminal states and leading to numerical divergence.
    
    \item \textbf{Controllability and Terminal Cost:} To implement a stabilizing terminal cost $Q_T$, we solve the Discrete Algebraic Riccati Equation (DARE):
    \begin{equation}
        P = A^\top P A - (A^\top P B)(R + B^\top P B)^{-1}(B^\top P A) + Q
    \end{equation}
    This requires the system linearization $(A, B)$ at the target equilibrium to be stabilizable. In under-actuated configurations, kinematic singularities can cause rank deficiencies in the controllability matrix, making the calculation of $Q_T$ impossible.

    \item \textbf{Instability to Dwell Time:} We observed numerical instability when requiring the system to maintain an unstable equilibrium for a final time interval (dwell time). 
    Consider the analogy of balancing a ball on a sharp peak: reaching the peak at time $T$ requires precision, but remaining there requires perfect force cancellation over time. Any numerical error $\epsilon$ at $t < T$ is amplified by the unstable eigenvalues of the system evolution matrix ($A^k$). This creates a "narrow ridge" in the cost landscape; slight deviations result in massive penalties, pushing variables into numerical overflow.

    \item \textbf{Linearization Validity:} The optimization relies on linearizing the non-linear dynamics around the current trajectory iteration. If the update step is too large, or if the trajectory deviates significantly into highly non-linear regions, the Taylor approximation breaks down, leading to valid descent directions becoming actual ascent directions in the non-linear cost landscape.
\end{itemize}

\subsection{Proposed Solution: Dynamic Horizon Extension}

To address the ill-conditioning and local minima problems described above, we implemented a \textbf{Dynamic Horizon Extension} strategy. 

Instead of attempting to solve the full problem $T_{final}$ immediately, we solve a sequence of sub-problems with increasing horizon lengths. This strategy conditions the optimization by ensuring the solver always operates within a valid local approximation.

\subsubsection{Theoretical Justification}
\begin{enumerate}
    \item \textbf{Conditioning:} For a short horizon $T$, the sensitivity matrix norm remains bounded, resulting in a well-conditioned Hessian and a larger basin of attraction for Newton's method.
    \item \textbf{Warm Starting:} The optimal solution for horizon $T$ is used as the initial guess for $T + \Delta T$. This "anchors" the new optimization in a feasible region of the state space, close to the physical constraints.
    \item \textbf{Iterative Refinement:} As the horizon expands, the solver primarily refines the control inputs locally. This avoids the explosive divergence associated with global searches in ill-conditioned landscapes.
\end{enumerate}

\subsubsection{Algorithm Implementation}
The procedure is defined as follows:

\begin{enumerate}
    \item \textbf{Initialize:} Set a short initial horizon $T_{curr} \ll T_{final}$ where the DARE terminal cost effectively captures the remaining cost-to-go.
    \item \textbf{Converge:} Execute the Newton solver until convergence criteria are met for the current $T_{curr}$.
    \item \textbf{Extend:} Use the computed trajectory $x^*(t)$ as the initial guess. Extend the horizon by $\Delta T$, padding the reference tail with the target equilibrium and evolving the initial guess via the system dynamics.
    \item \textbf{Repeat:} Increment $T_{curr} \leftarrow T_{curr} + \Delta T$ and repeat until $T_{curr} \geq T_{final}$ and the terminal error satisfies $\|\mathbf{x}_T - \mathbf{x}_{target}\| < \epsilon$.
\end{enumerate}
